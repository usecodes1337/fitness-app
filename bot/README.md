# 🤖 Telegram-бот для фитнес-приложения «90 дней»

Этот бот предназначен для привлечения аудитории из социальных сетей (Instagram, TikTok, YouTube Shorts, VK), выдачи пошаговой инструкции по установке PWA на экран смартфона и последующих рассылок (акции, скидки, мотивация, анонсы в Telegram-канал).

---

## 🚀 Быстрый запуск за 2 минуты

### Шаг 1. Получить токен бота
1. Открой в Telegram [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`, укажи имя (например, `90 Дней до рельефа | Фитнес Трекер`) и юзернейм (например, `MyFitness90DaysBot`).
3. Скопируй выданный токен API (например: `7123456789:AAH...`).

### Шаг 2. Настроить файл `.env`
В папке `bot/` создай файл `.env` (или переименуй `.env.example` в `.env`) и заполни:
```env
BOT_TOKEN=твой_токен_от_botfather
WEB_APP_URL=https://твое-приложение.vercel.app
TELEGRAM_CHANNEL_URL=https://t.me/твой_канал
ADMIN_TELEGRAM_ID=твой_личный_id_из_@userinfobot
```

### Шаг 3. Запустить бота
В терминале перейди в папку `bot` и запусти:
```bash
cd bot
npm install
npm start
```

---

## 🛠️ Возможности бота:

1. **Команда `/start`**:
   * Приветствует пользователя по имени.
   * Презентует возможности приложения.
   * Выдает кнопки:
     * 🚀 **«Открыть приложение»**
     * 📱 **«Инструкция по установке на телефон»**
     * 📢 **«Наш Telegram-канал»**
   * Сохраняет пользователя в локальную базу `subscribers.json`.

2. **Инструкция по установке (PWA)**:
   * Пошагово объясняет для **iPhone (Safari)**: *Поделиться ➔ «На экран Домой» ➕*.
   * Пошагово объясняет для **Android (Chrome)**: *Меню ⋮ ➔ «Установить приложение» ➕*.

3. **Команды администратора (доступны только вам по `ADMIN_TELEGRAM_ID`)**:
   * `/stats` — показывает количество людей, запустивших бота.
   * `/broadcast <текст>` — мгновенно рассылает ваше сообщение всем пользователям бота (например, скидки на доступ, напоминания или приглашение в Telegram-канал).
